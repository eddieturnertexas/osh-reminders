Config-driven dispatch

osh_config_<layer>_stream
One row per stream: which notebook runs it, its source and target catalog, schema and table, and the secret pointers for the API.
osh_config_<layer>_status
Rebuilt from the stream table each run. Carries RunOrder and the enabled / running / completed flags the orchestrator loops over.
osh_config_log_header
One row per run phase — Bronze Started, Bronze Ended, and the same for silver and gold.
osh_config_log_header_detail
One row per event: START, a PROGRESS row per micro-batch, SUMMARY, STOP, SKIPPED for a disabled stream, ERROR with the phase and trace.
